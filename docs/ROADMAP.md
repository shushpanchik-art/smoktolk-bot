### ☐ 3.2 🔴 Категорийный доступ к ассортименту по возрасту
- **Файлы:** `handlers/catalog.py`, `catalog_norm.py` (`CATEGORY_META`), `db.py` (`age_verified`)
- **Что:** разделить категории на 2 группы:
  - **Свободные (без возраста):** уголь `ugol`, кофе `coffee`, глицерин `glicerin`, ароматизаторы, энергетики
  - **18+ (только `age_verified=1`):** всё остальное (табак, жидкости, устройства и т.д.)
  Незаверенным юзерам категории 18+ либо скрыты, либо помечены «🔞 нужен возраст».
- **Оценка:** 1.5 ч · **Риск:** высокий (логика доступа + маппинг категорий)
- **Чек-лист:**
  - [ ] Определить в `catalog_norm.py`: `FREE_CATEGORIES = {...}` (сверить ключи с CATEGORY_META)
  - [ ] В `handlers/catalog.py`: фильтровать список категорий по `age_verified`
  - [ ] При попытке открыть 18+ без возраста → предложить пройти верификацию
  - [ ] Проверить оба сценария (заверен / не заверен)
  - [ ] Тест в `tests/`
