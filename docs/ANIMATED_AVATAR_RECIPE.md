# Рецепт анимированной аватарки бота Telegram

## Контекст

Telegram Bot API 9.0+ метод `setMyProfilePhoto` с
`InputProfilePhotoAnimated` принимает MP4-vидео как анимированную аватарку, но *молча деградирует* file до статичного JPG, если он не соответствует скрытым требованиям. Официальная документация
ограничивается формулировкой `MPEG4 format` и не задаёт точных параметров.

Все известные эмпирические требования получены сообществом разработчиков через эксперименты:
публичный бот [@LiveAvaBot](https://t.me/LiveAvaBot) как эталон и серия статей
*@liveavabot* на dev.to.

## Проверенная рабочая формула (2026)

### Требования к видео

| Параметр        | Значение                       |
|----------------|--------------------------------------|
| Контейнер      | MP4 с `+faststart` (moov в начале)  |
| Видеокодек     | H.264, profile **high**, level 4.0  |
| Разрешение     | **800×800** (квадрат)               |
| FPS             | **30**                                |
| pix_fmt        | yuv420p                             |
| B-frames       | **отключены** (`-bf 0`)             |
| Аудио          | отсутствует                         |
| Длительность   | до 10 сек, рекомендуется ≤ 9       |
| Размер файла   | до 2 MB                               |

### FFmpeg-rецепт

    ffmpeg -y -v error \
      -i SOURCE.mp4 \
      -t 9 \
      -vf "scale=800:800:flags=lanczos,fps=30,format=yuv420p" \
      -c:v libx264 \
      -profile:v high \
      -level 4.0 \
      -preset medium \
      -crf 23 \
      -maxrate 1400k \
      -bufsize 2800k \
      -bf 0 \
      -pix_fmt yuv420p \
      -an \
      -movflags +faststart \
      data/avatr2_botpic.mp4

## Поведение в клиентах Telegram

- **Мобильные клиенты (iOS / Android)**: анимация играет в
  полноэкранном профиле бота при открытии туда зацикленно.
- **Desktop (macOS / Windows)**: аналогично — а анимация играет
  в полноэкранном профиле.
- **В списке чатов и в шапке открытого чата**: показывается
  только статичный кадр. Это штатное поведение Telegram,
  а не баг нашего видео или формулы.

## Методика тестирования (важно)

Telegram **агрессивно кеширует** аватарки. Без принудительной очистки
 кеша клиент показывает старую статичную версию даже после
успешной заливки.

1. **Очистить кеш Telegram**
   - iOS: Настройки → Данные и память → Использование сети → Очистить кеш
   - Android: Настройки → Данные и память → Использование памяти → Очистить кеш
2. **Полностью** закрыть Telegram и открыть заново.
3. Найти бота через **поиск** (а не через недавние чаты).
4. Нажать на круглую аватарку в шапке чата → откроется
   полноэ�+ аноранный профиль → именно здесь играет анимация.
5. Эталон для сравнения — публичный бот **@LiveAvaBot**.

## Скрипт заливки

Смотри `scripts/set_animated_avatar.py` (добавлен в PR #39):

    python scripts/set_animated_avatar.py

Скрипт берёт `data/avatr2_botpic.mp4` и заливает его через
`set_my_profile_photo` с `main_frame_timestamp=1.5`.
