SMOKTOLK BOT — PROJECT_BOOK (справочник проекта)
================================================
Обновлено по факту разведки кода. Истина — код + docs/SPEC.md, docs/ROADMAP.md, CHANGELOG.md.

НАЗНАЧЕНИЕ
Telegram-бот табачного магазина SMOKTOLK: каталог товаров, профиль/баллы/уровни,
рефералы, подарки по QR, списание баллов по QR/бэкап-коду через кассу (POS webhook),
верификация возраста 18+, админ-панель, удаление профиля (soft-delete), инфо о магазине.

РАЗМЕЩЕНИЕ И ЗАПУСК
Код:      /opt/smoktolk/bot
venv:     /opt/smoktolk/bot/venv/bin/python  (Python 3.11.2)
systemd:  smoktolk-bot.service (loaded/active/running, "Smoktolk Telegram Bot")
          drop-in: systemd/smoktolk-bot.service.d/{10-alerts.conf,20-resources.conf}
Режим:    POLLING (bot.py:102 dp.start_polling, allowed_updates=resolve_used_update_types()).
          webhook.py тоже подключается (webhook.setup_webhook(app)) для приёма POST от кассы (POS).
БД:       SQLite, aiosqlite. DB_PATH (по умолч. smoktolk.db, факт в data/*.db). Миграции при старте:
          msg_wipe.migrate_msg_log() + миграции db_deletion (deleted_at/deleted_by/purged_at/warned_before_purge).
Управление: sudo systemctl restart|status smoktolk-bot ; journalctl -u smoktolk-bot -n50 [--since ...]

СТРУКТУРА (корень плоский, не app/)
bot.py            — точка входа: init, миграции, регистрация ROUTERS, msg_wipe middleware
                    (bot.session.middleware.register — НЕ .middleware(fn), падает), polling.
config.py         — все настройки из ENV + дефолты; STORE_* и _build_store_info_text (адрес,
                    часы, парковка STORE_PARKING, 2GIS/Яндекс.карты, телефон), CHANNEL_URL, BOT_USERNAME.
db.py             — основная БД-логика, таблицы, баллы/уровни, подарки, redemptions, QR-токены
                    (secrets.token_urlsafe), soft_delete_profile.
db_deletion.py    — soft-delete профиля: soft_delete_profile, restore_profile,
                    warn_before_purge_candidates, purge_expired_profiles, migrate_deletion_columns
                    (deleted_at/deleted_by/purged_at/warned_before_purge). Баллы/покупки живут, потом purge.
webhook.py        — aiohttp: POST /pos/redeem {qr_token|backup_code} — списание баллов кассой.
                    WEBHOOK_MODE=stub|live, WEBHOOK_TOKEN защита. Fallback по backup_code — TODO (SPEC).
catalog.py, catalog_norm.py — парсинг/нормализация прайса (openpyxl read_only, 104s->2s), CATEGORY_META.
keyboards.py      — inline-клавиатуры: kb_main (кнопка "📢 Наш канал @SMOKTOLK" -> CHANNEL_URL),
                    kb_profile, kb_admin_*, реф-ссылка/поделиться, "✉️ Написать" (https://t.me/{username}).
product_images.py — картинки товаров. tasks.py — фоновые задачи. utils.py — make_qr и пр.
msg_wipe.py / msg_wipe_mw.py — учёт message_id бота (таблица bot_messages) + вайп своих сообщений
                    моложе 48ч (batch deleteMessages<=100, fallback поштучно) при удалении профиля.
crash_alert.py    — алерт админу при падении. db_deletion — см. выше.
handlers/__init__.py -> ROUTERS = [start, profile, gifts, catalog, referral, rules, verify, admin,
                    _admin_addon, address].router
services/         — admin_notify.py (уведомления админу).
middlewares/      — deleted_guard.py (DeletedGuard: перехват удалённых профилей -> онбординг восстановления).
docs/             — AI_ONBOARDING.md, BACKUP.md, OPERATIONS.md, ROADMAP.md, SECURITY.md,
                    ANIMATED_AVATAR_RECIPE.md. Корень: README.md, SPEC.md, CHANGELOG.md,
                    CONTRIBUTING.md, ONBOARDING_AI.md.
scripts/          — backup.sh и семейство offsite/full-offsite + *_healthcheck.sh, notify_admin.sh
                    (читает BOT_TOKEN/ADMIN_ID из .env, шлёт sendMessage), deploy_systemd.sh,
                    set_animated_botpic.py, git-hooks/ + setup-hooks.sh (pre-push защита main).
systemd/          — bot + backup/backup-offsite/backup-full-offsite (.service+.timer) +
                    *-healthcheck.{service,timer} + *-alert.service. Внешние таймеры для бэкапов/алертов.
assets/, data/, logs/, media(product_images).
